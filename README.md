# AI-prakriti-identification-system

This project is a hybrid system to identify Ayurvedic body type (Prakriti) using facial feature analysis and an adaptive questionnaire.

## Technologies
- Python
- OpenCV
- MediaPipe
- NumPy

## Features
- Face detection
- Facial landmark detection
- Feature extraction
- Data preprocessing

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run:
   python src/main.py
